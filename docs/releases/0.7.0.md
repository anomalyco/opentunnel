## Rust crate

- `Tunnel::ready()` resolves once the bridge first attaches, so the public URLs work, or returns the fatal attach error (`bad_token`, `cert_not_ready`, …) that stopped the tunnel first, like `connect()` in `@opentunnel/client`. Dropping the future leaves the tunnel running (#82).

```rust
let tunnel = client.connect("default", routes)?;
tunnel.ready().await?;
```
